# 基于遗传算法的时间精力双维度规划 - 优化版本

## 项目概述

这是一个基于遗传算法的时间和精力双维度任务调度系统，能够智能安排任务在最合适的时间段执行，以最大化效率和匹配个人精力状态。

## 优化内容

### 1. 代码结构优化
- **模块化设计**：将代码拆分为多个功能模块（config.py, task.py, energy_curve.py, schedule_engine.py, ga_solver.py, visualization.py）
- **单一职责原则**：每个模块只负责特定功能，提高代码可维护性
- **配置管理**：使用Config类统一管理所有配置参数

### 2. 性能优化
- **批量计算**：实现了批量获取精力值的方法，提高计算效率
- **预计算缓存**：预计算常用值，减少重复计算
- **算法优化**：改进了冲突检测和时间槽枚举算法

### 3. 可扩展性增强
- **易于扩展**：模块化设计使得添加新的调度策略或任务类型变得容易
- **灵活配置**：通过配置类轻松调整算法参数

### 4. 代码质量提升
- **更好的命名**：使用更清晰的变量和函数命名
- **减少重复**：消除代码重复，提取公共函数
- **类型提示**：为关键函数添加类型提示

## 算法特点

1. **双维度优化**：同时考虑时间和精力因素
2. **多日调度**：支持跨多天的任务规划
3. **约束处理**：处理课程表、工作时间等硬约束
4. **智能解码**：采用全局候选时间槽的解码策略
5. **多样化策略**：支持多种解码策略（first_fit, best_fit, stochastic）

## 使用场景

- 学生课程表与学习任务的智能安排
- 工作日程的高效规划
- 时间敏感任务的优先级调度
- 个人精力管理与任务匹配

## 算法参数可调

- `POP_SIZE`: 种群大小
- `GENERATIONS`: 迭代代数
- `MUT_RATE`: 变异率
- `CROSS_RATE`: 交叉率
- `DECODE_STRATEGY`: 解码策略
- 各项适应度权重
